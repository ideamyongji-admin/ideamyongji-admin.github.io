관리자 비밀번호 최초 설정

아직 관리자 비밀번호가 설정되지 않았습니다. 앞으로 이 페이지에 들어올 때 사용할 비밀번호를 정하고, GitHub 토큰을 함께 입력해 주세요. 비밀번호는 원문이 아닌 해시값으로만 저장소에 저장됩니다.

토큰 발급 방법 보기
  1. github.com/settings/personal-access-tokens/new 접속 (GitHub 로그인 필요)
  2. Token name: 원하는 이름 입력 (예: idea-site-admin)
  3. Repository access → Only select repositories → ideamyongji.github.io 선택
  4. Permissions → Repository permissions → Contents: Read and write 선택
  5. Generate token 클릭 후 발급된 토큰(github_pat_...)을 복사해 위 입력창에 붙여넣기

GitHub 토큰 관리

아래 안내에 따라 발급받은 GitHub 토큰을 입력하고 저장하세요. 토큰은 이 브라우저에만 저장되며, GitHub API 외에는 어디로도 전송되지 않습니다.

토큰 발급 방법 보기
  1. github.com/settings/personal-access-tokens/new 접속 (GitHub 로그인 필요)
  2. Token name: 원하는 이름 입력 (예: idea-site-admin)
  3. Repository access → Only select repositories → ideamyongji.github.io 선택
  4. Permissions → Repository permissions → Contents: Read and write 선택
  5. Generate token 클릭 후 발급된 토큰(github_pat_...)을 복사해 위 입력창에 붙여넣기
  6. 토큰은 한 번만 표시되니 안전한 곳에 백업해 두세요. 만료되면 같은 방법으로 재발급하면 됩니다.
